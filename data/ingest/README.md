# Ingest manifests

The ingestion pipeline ([`whereabout_ml.ingest`](../../ml/src/whereabout_ml/ingest.py)) turns a
list of Wikimedia Commons file titles into a manifest of usable training images. The files
here are generated by the [Ingest sample workflow](../../.github/workflows/ingest.yml), which
runs it on the catalog's Commons files; they are not hand-edited.

| File | Contents |
| --- | --- |
| `sample_manifest.csv` | One row per file that passed the checks, near-duplicates included and marked |
| `sample_rejected.csv` | `title`, `reason` for every file that was dropped |
| `sample_manifest.meta.json` | Counts, licenses, hash settings, and catalog rows whose curated license differs from the one Commons reports |

## What the pipeline checks

1. **License capture.** The license, author, license URL and "attribution required" flag come
   from Commons' own `extmetadata`, not from scraping. The license is normalised to the
   allow-list — CC0, public domain, CC BY and CC BY-SA (any version or port). Anything else
   (NC, ND, GFDL-only, missing) is rejected, as is a file with no author to credit under a
   license that needs one.
2. **Privacy and usefulness.** Files tagged with personality rights (identifiable people),
   non-photos (SVG, video) and files without camera coordinates are rejected.
3. **Perceptual-hash dedupe.** A 330 px thumbnail is reduced to a 64-bit DCT hash (pHash).
   Files within 8 bits of each other count as the same photo: the larger original is kept and
   the other gets `duplicate_of` (its `pageid`) and the bit `distance`. Duplicates stay in the
   manifest so that a later split can keep both copies on the same side.

## Manifest columns

| Column | Meaning |
| --- | --- |
| `pageid` | Commons page id, stable across renames |
| `title`, `source_url` | Commons file title and description page (attribution link) |
| `thumb_url` | The thumbnail that was hashed |
| `width`, `height` | Original size in pixels |
| `lat`, `lon` | Camera location from the file's Commons coordinates |
| `author`, `license`, `license_url`, `attribution_required` | Credit, as Commons states it |
| `sha1` | SHA-1 of the original file, from Commons |
| `phash` | 64-bit perceptual hash, hex |
| `duplicate_of`, `distance` | `pageid` of the kept copy and the Hamming distance, if a near-duplicate |

Run it locally (needs `python -m pip install -e "ml[ingest]"` and access to Commons):

```bash
ingest-commons --catalog data/curation/photos.csv --out-dir data/ingest --name sample
ingest-commons --titles my_titles.txt --out-dir data/ingest --name batch1   # one title per line
```

All images are Wikimedia Commons files under the license and author recorded in each row.
