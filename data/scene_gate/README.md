# Scene gate

The scene gate is a CLIP-based check that turns away images that are not outdoor place photos
(people, interiors, signs and text, maps, paintings and diagrams) before they reach the
geolocation models. Its code is in
[`scene_gate.py`](../../ml/src/whereabout_ml/scene_gate.py) and
[`run_scene_gate.py`](../../ml/src/whereabout_ml/run_scene_gate.py). The files here are generated by
the [Scene gate workflow](../../.github/workflows/scene_gate.yml), which commits them to `main`.

| File | Contents |
| --- | --- |
| `rejects.csv` | The labelled reject fixture: `title`, `label`, `image_url`, `author`, `license`, `source_url` |
| `thresholds.json` | The calibrated thresholds |
| `report.json`, `report.md` | The calibration report, machine- and human-readable |
| `scores.csv` | Per-image gate scores for the catalog photos and the rejects |

## How rejects are labelled

[`reject_fixture.py`](../../ml/src/whereabout_ml/reject_fixture.py) draws files from Wikimedia
Commons categories, listed in `LABEL_CATEGORIES`: `people`, `indoor`, `text` and `not_photo`.
**The label is the Commons category a file was drawn from. It is not a human review**, so some
rows will be mislabelled (a portrait in a sign category, a landscape in a screenshot category).
Only openly licensed JPEG and PNG files are kept (CC0, public domain, CC BY, CC BY-SA), up to
`--per-label` per label, in title order. No coordinates are needed. License and author are recorded
per row in `rejects.csv`; attribution links back to the Commons page in `source_url`. The fixture
is built once and reused; pass `--force` to rebuild it.

## How thresholds are calibrated

Every hand-reviewed photo in `data/curation/photos.csv` must pass the gate, so thresholds are set
with `max_false_reject` 0 on the catalog. Within that limit, the rejects fixture shows how many
unwanted images each label would still let through.

## Running locally

```sh
pip install -e api -e eval -e "ml[clip]"
python -m whereabout_ml.reject_fixture --out data/scene_gate/rejects.csv
python -m whereabout_ml.run_scene_gate --catalog data/curation/photos.csv \
  --rejects data/scene_gate/rejects.csv --images .cache/images --out data/scene_gate
```
